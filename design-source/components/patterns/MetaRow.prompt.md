The metadata line: place, headcount, status. Stack two or three per card, 8px apart, in a fixed order — location, then people, then status.

```jsx
<MetaRow icon="location-outline">Palestra Comunale</MetaRow>
<MetaRow icon="people-outline">14/18 presenti</MetaRow>
<MetaRow icon="play-circle-outline" color="var(--eg-success)">Allenamento attivo</MetaRow>
```

Only the icon carries the status colour; the text stays secondary grey.
