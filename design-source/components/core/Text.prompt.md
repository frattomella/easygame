Strong hierarchy is part of the signature: a tracked uppercase `eyebrow` above, a tight 800-weight `display`/`numeral` beneath, then calm 400 body.

```jsx
<Text type="eyebrow" tone="onBrandMuted">Programma di oggi</Text>
<Text type="display" tone="onBrand">2 allenamenti</Text>
<Text type="numeral">18:00</Text>
<Text type="small" tone="secondary">Palestra Comunale</Text>
```

On the navy sky use the `onBrand*` tones; on glass use `primary`/`secondary`/`faint`.
